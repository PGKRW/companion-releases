# Companion Releases

Public download repository for Android test builds of the Companion prototype.

## Download

Current Android APKs are published through GitHub Releases.

These builds are prototypes for private testing and are not official apps of any school, portal provider, WebUntis, EduPage, LEO or another third-party service.

## Important

- Use only with accounts and data you are authorized to access.
- The app is a prototype and may be incomplete or contain errors.
- Binding school-related actions, confirmations, bookings, notifications or deadlines must still be handled through the respective official system.
- Do not rely on this app as the sole source for time-critical or legally relevant information.

## Privacy and security

The public repository contains release/download material only. It does not contain the private source repository, project history, credentials, portal passwords, cookies, QR secrets, signing keys or other private project secrets.

Android APKs can always be inspected or decompiled to some degree. The release build is therefore minified, but no security-relevant secret is intended to rely on obscurity inside the APK.

## Verification

Where available, each APK is accompanied by a SHA-256 checksum.
